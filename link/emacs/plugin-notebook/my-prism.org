Much like the =rainbow-delimiters= and =rainbow-blocks= packages, =prism= colorizes
code blocks based on how deeply nested they are, though it is a newer plugin
that brands itself as respecting existing non-color face properties (such as
font size and weight) while the older plugins do not. Thus, =prism= is an
*alternative* to =rainbow-delimiters= and =rainbow-blocks=.

*NOTE:* =prism= is not compatible with =rainbow-mode=, while =rainbow-delimiters= is
compatible. For that reason alone, you may wish to forego this plugin.

#+begin_src emacs-lisp
  (use-package prism
    ;; I prefer to use `rainbow-delimiters' and `rainbow-mode'
    :disabled
    :hook
    ;; Activate prism for Lisp-based major modes
    ((cider-repl-mode
      clojure-mode
      common-lisp-mode
      emacs-lisp-mode
      ielm-mode
      lisp-mode
      lisp-data-mode
      lisp-interaction-mode
      slime-repl-mode
      sly-mrepl-mode)
     . prism-mode)
    ;; For whitespace-sensitive languages, we must activate `prism-whitespace-mode' instead.
    ((python-mode python-ts-mode haskell-mode)
     . prism-whitespace-mode))
#+end_src
