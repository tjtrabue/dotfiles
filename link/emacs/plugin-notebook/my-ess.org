[[https://ess.r-project.org/Manual/ess.html][ESS]] is an Emacs package designed to support editing of scripts and interaction
with various statistical analysis programs, such as R, S-Plus, SAS, Stata, and
OpenBUGS/JAGS.

Consult [[https://ess.r-project.org/Manual/ess.html#Interacting-with-statistical-programs][the manual]] for usage instructions.
