Plugins and configuration for regular expression support within Emacs.

* relint
Code linter (that is, a syntax/style checker) for regular expressions.

#+begin_src emacs-lisp
  (use-package relint)
#+end_src

* visual-regexp
Makes regular expressions look nicer in Emacs Lisp strings.

#+begin_src emacs-lisp
  (use-package visual-regexp
    :demand t
    :general
    (my/user-leader-def 'global
      "r r" 'vr/replace
      "r q" 'vr/query-replace))
#+end_src

* visual-regexp-steroids
An enhancement package for =visual-regexp= that enables Python and PCRE2 regexps.

#+begin_src emacs-lisp
  (use-package visual-regexp-steroids
    :after visual-regexp
    :demand t)
#+end_src
