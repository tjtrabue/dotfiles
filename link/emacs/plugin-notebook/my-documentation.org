Documentation is an everyday part of life for the diligent programmer, and any
decent editor should support useful, configurable, and beautiful presentations
for documentation.

* ElDoc [built-in]
Display Lisp object documentation strings in the echo area. Although this
minor-mode works with Emacs Lisp by default, plugins such as SLIME for Common
Lisp and CIDER for Clojure integrate their documentation systems with ElDoc, as
well.

#+begin_src emacs-lisp
  (use-package eldoc
    :ensure nil
    :straight (:type built-in)
    :delight
    :custom
    ;; How to display messages in the echo area.  Eldoc can display the first
    ;; returned message, or compose all of the returned messages into a single
    ;; string.
    (eldoc-documentation-strategy #'eldoc-documentation-compose-eagerly)
    ;; Whether ElDoc is allowed to resize the echo area to display docs.
    ;; If t, never truncate. If nil, ElDoc will always truncate doc strings to fit
    ;; the echo area. If a positive number, it represents the number of screen lines
    ;; of documentation ElDoc puts into the echo area. IF `truncate-sym-name-if-fit',
    ;; the part of the doc string representing a symbol's name may be truncated
    ;; if it will enable the rest of the doc string to fit on a single line.
    (eldoc-echo-area-use-multiline-p 'truncate-sym-name-if-fit)
    :init
    (global-eldoc-mode 1))
#+end_src

* eldoc-box
Display ElDoc documentation in a child frame. The child frame is selectable and
scrollable with the mouse, even though the cursor is hidden within the child
frame.

#+begin_src emacs-lisp
  (use-package eldoc-box
    ;; Only use this package for GUI Emacs.
    :if (display-graphic-p)
    :delight
    (eldoc-box-hover-mode nil eldoc-box)
    (eldoc-box-hover-at-point-mode nil eldoc-box)
    :hook
    ;; Minor-mode that displays ElDoc documentation in a child frame in a top corner of the
    ;; frame.
    (eldoc-mode . eldoc-box-hover-mode)
    ;; An alternative to `eldoc-box-hover-mode' that displays the child frame at point instead of in a
    ;; top corner. This minor mode is noticeably slower than its alternative.
    ;; (eldoc-mode . eldoc-box-hover-at-point-mode)
    :custom
    ;; Whether to only display multi-line ElDoc messages in the child frame, in which case single-line
    ;; messages will still appear in the echo area.
    (eldoc-box-only-multi-line nil))
#+end_src
