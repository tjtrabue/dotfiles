This is a wiki article on the purpose and configuration of common Linux system
files.

* =/etc/systemd/logind.conf=
** Purpose
This is one of the primary Systemd configuration files used to manage user
session details. It contains copious parameters for power management, i.e., when
and how the system suspends, how long of an idle period elapses before
suspending occurs, what happens when the user presses the power button, etc.

* =/etc/mkinitcpio.conf=
** Purpose
An Arch Linux file used to configure the =mkinitcpio= shell script that creates
the initial ramdisk image that Arch uses to bootstrap itself. One notable
use for this file is /early loading of kernel module parameters/. That is, if you
want NVIDIA parameters to take effect at the earliest possible time, specify
them in this file.
